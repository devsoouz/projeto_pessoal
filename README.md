> Este é um projeto pessoal desenvolvido para praticar e fixar meus conhecimentos em Front-end. Criei uma página de apresentação completa para aplicar conceitos fundamentais de estilização e estrutura web.

---

## 🎯 Objetivo do Projeto

O objetivo principal deste projeto foi sair da teoria e colocar a mão na massa para:
- Estruturar uma página completa do zero usando **HTML5**.
- Criar um layout visualmente agradável usando **CSS3**.
- Aprender a utilizar o framework **Bootstrap 5** para acelerar o desenvolvimento e garantir responsividade (mobile-first).
